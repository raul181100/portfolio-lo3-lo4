# Spring Boot

Spring Boot es un framework de Java que simplifica crear aplicaciones del lado del servidor. Configura automáticamente muchas piezas (servidor embebido, conexión a la base de datos, seguridad) para que puedas empezar a programar la lógica en pocos minutos. Sigue la idea de "convención sobre configuración" y se apoya en el framework Spring.

**Lo que usa HouseMate:**
- Controladores REST para las APIs
- JPA/Hibernate para guardar datos en PostgreSQL
- Anotaciones como `@Entity` o `@Enumerated`

> [!tip] Dato curioso
> Puedes generar un proyecto base en segundos desde [start.spring.io](https://start.spring.io), la herramienta oficial llamada Spring Initializr.
