# Diagrams

Un diagrama es una representación visual de un sistema: muestra sus partes y cómo se relacionan, sin necesidad de leer código. En software sirven para explicar la arquitectura a otras personas y para documentar sin sobrecargar el texto. El modelo https://c4model.com propone verlos por niveles de zoom: contexto, contenedores, componentes y código.

**Herramientas para hacerlos:**
- draw.io (diagrama libre, gratis, sin cuenta)
- Mermaid (diagramas escritos como texto dentro de Markdown)
- PlantUML (diagramas UML a partir de código)
- Excalidraw (estilo dibujado a mano)

> [!tip] Dato curioso
> El modelo C4 lo creó Simon Brown y solo tiene cuatro niveles: contexto, contenedores, componentes y código.
